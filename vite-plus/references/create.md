# 新建项目

仅在用户要创建新项目或新增工作区包时读取。先完成主文件的文档、现场和目标 CLI 检查。

1. 读取 https://viteplus.dev/guide/create。
2. 确定框架或模板、目标目录、包管理器、精确 Vite+ 发布版或预览版。沿用现有工作区约定；缺失的关键选择向用户确认。
3. 通过目标 CLI 运行 `help create`，据其输出选择支持的参数；需要时运行 `create --list`。不要用其他版本的参数猜测当前 CLI 行为。
4. 检查目标路径，使用未占用目录；发现既有项目文件时停下确认，不允许覆盖。新增工作区包时保留工作区已有配置。
5. 用 `vp create` 脚手架创建。无全局 CLI 时使用主文件的临时 CLI 调用方式，例如：

   ```sh
   pnpm dlx --package=vite-plus@1.0.0 vp help create
   npx --package=vite-plus@1.0.0 vp help create
   ```

   以上仅展示二选一的帮助命令；替换版本后，用该版本帮助提供的模板及目录参数执行 `create`。预览版按主文件规则添加 registry 参数。
6. 审查生成文件、依赖及钩子。不要为省去交互自动批准所有依赖构建脚本；按实际依赖需求确认。避免额外生成用户不需要的编辑器或代理配置。
7. 回到主文件的共同验证：安装、检查、测试、应用构建或库打包，并报告开发服务器和任务运行方法。
